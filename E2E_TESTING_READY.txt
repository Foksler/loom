================================================================================
  TROUBLESHOOTING
================================================================================

Port 3000 in use:
  lsof -ti:3000 | xargs kill -9

Tests timeout:
  - Increase timeout in config
  - Check dev server is running
  - Look for network issues

Visual tests fail:
  - Update baselines: npm run test:e2e:update-snapshots
  - Check for environment differences

Flaky tests:
  - Add proper waits (not delays)
  - Use page.waitForLoadState('networkidle')
  - Verify DOM stability

Element not found:
  - Use UI mode to inspect: make test-e2e-ui
  - Check selectors with Playwright Inspector

See TESTING_GUIDE.md troubleshooting section for more help.
