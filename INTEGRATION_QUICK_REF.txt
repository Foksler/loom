QUICK START
───────────

1. Start Backend
   LOOM_SERVER_DATABASE_URL=sqlite:./loom.db cargo run --bin loom-server

2. Start Frontend (separate terminal)
   LOOM_SERVER_URL=http://localhost:3000 cargo leptos serve

3. Access Application
   http://localhost:3000

4. Run Integration Tests
   ./tests/integration_e2e.sh http://localhost:3000

API ENDPOINTS
─────────────

GET    /api/web/threads                    Get all threads
GET    /api/web/threads/{id}               Get single thread
PUT    /api/web/threads/{id}               Create thread
POST   /api/web/threads/{id}               Update thread
DELETE /api/web/threads/{id}               Delete thread
GET    /api/web/threads/search?q={query}   Search threads

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CURL EXAMPLES
─────────────

# Get threads
curl http://localhost:3000/api/web/threads?limit=50

# Create thread
curl -X PUT http://localhost:3000/api/web/threads/T-ABC123 \
  -H "Content-Type: application/json" \
  -d '{"title": "My Thread"}'

# Get thread
curl http://localhost:3000/api/web/threads/T-ABC123

# Update thread
curl -X POST http://localhost:3000/api/web/threads/T-ABC123 \
  -H "Content-Type: application/json" \
  -d '{"title": "Updated Title"}'

# Delete thread
curl -X DELETE http://localhost:3000/api/web/threads/T-ABC123

# Search threads
curl "http://localhost:3000/api/web/threads/search?q=webpack"

DATA MODELS
────────────

ThreadSummary:
  id: String
  title: Option<String>
  created_at: String (ISO 8601)
  updated_at: String (ISO 8601)
  last_activity_at: String (ISO 8601)
  provider: Option<String>
  model: Option<String>

Thread:
  [All ThreadSummary fields] +
  conversation: ConversationSnapshot

ConversationSnapshot:
  messages: Vec<MessageSnapshot>

MessageSnapshot:
  role: String ("user", "assistant", "system")
  content: String

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VALIDATION RULES
─────────────────

Thread Title:
  - Required (non-empty)
  - Max 500 characters
  - Returned on create/update

Thread ID:
  - Format: T-{UUID-12-chars}
  - Generated on create
  - Required for get/update/delete

Search Query:
  - Required (non-empty)
  - Max 200 characters
  - Case-insensitive

COMMON ISSUES & SOLUTIONS
──────────────────────────

Issue: Server not responding
→ Check LOOM_SERVER_URL environment variable
→ Ensure backend is running: cargo run --bin loom-server

Issue: Build fails
→ Run: make build
→ Check Rust version: rustup update

Issue: Tests failing
→ Run: ./tests/integration_e2e.sh http://localhost:3000
→ Check database connection

Issue: Configuration not working
→ Set LOOM_SERVER_URL before starting either service
→ Check environment variables are exported
