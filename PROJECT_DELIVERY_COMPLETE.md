## DEPLOYMENT OPTIONS

### 1. Docker Compose
```bash
docker-compose -f deploy/docker-compose.yml up -d
```
**Time to deploy**: 2-5 minutes  
**Best for**: Local dev, staging  

### 2. Kubernetes
```bash
kubectl apply -f deploy/kubernetes.yaml
```
**Time to deploy**: 5-10 minutes  
**Best for**: Production, scalability  

### 3. Binary (Systemd)
```bash
./deploy/build.sh && ./deploy/deploy.sh
systemctl start loom-web
```
**Time to deploy**: 3-5 minutes  
**Best for**: Single server, minimal overhead  

### 4. Nix Flake
```bash
nix flake update && nix run .
```
**Time to deploy**: 1-3 minutes  
**Best for**: Declarative infrastructure
