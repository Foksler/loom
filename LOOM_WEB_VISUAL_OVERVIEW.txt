STATE MANAGEMENT
════════════════

GLOBAL STATE (AppState Context):
┌─────────────────────────────────────────┐
│ pub struct AppState {                   │
│   active_thread_id: RwSignal<...>,      │
│   threads: Resource<Vec<Thread>>,       │
│   streaming_state: RwSignal<...>,       │
│   query_settings: RwSignal<...>,        │
│ }                                       │
│                                         │
│ Available to ALL components via         │
│ use_app_state() context hook            │
└─────────────────────────────────────────┘

LOCAL STATE (Per-Component):
┌─────────────────────────────────────────┐
│ let (form_input, set_input) =           │
│   create_signal(String::new());         │
│                                         │
│ Used for:                               │
│ • Form field values                     │
│ • UI toggles (modal, menu)              │
│ • Ephemeral state (hover, focus)        │
└─────────────────────────────────────────┘

STYLING APPROACH
════════════════

Tailwind CSS (Utility-First):
  class="px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700"

Design Tokens (CSS Variables):
  :root {
    --color-brand: 3 102 214;
    --color-neutral: 55 53 47;
    --radius-md: 0.5rem;
  }

Component Shortcuts (@layer):
  .btn { @apply px-3 py-1.5 font-medium rounded-md ... }
  .btn-primary { @apply btn bg-blue-600 text-white ... }


STREAMING LIFECYCLE
═══════════════════

User submits prompt
        │
        ▼
  StreamingState::Starting
        │
        ▼
  start_streaming(thread_id, callback)
        │
        ▼
  Browser connects to SSE endpoint (/api/threads/:id/stream)
        │
        ▼
  Server pushes chunks: StreamEvent::Chunk { text }
        │
        ▼
  Component receives chunk, updates Signal:
  set_state.update(|s| buffer.push_str(&chunk))
        │
        ▼
  Signal change triggers reactive re-render
        │
        ▼
  ConversationView displays new text incrementally
        │
        ▼
  Server sends: StreamEvent::Done
        │
        ▼
  StreamingState::Idle
        │
        ▼
  Refetch thread to sync message history
