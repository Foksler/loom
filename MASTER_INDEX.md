## ⚡ Command Quick Reference

```bash
# Development
cd crates/loom-web && cargo leptos watch

# Check status
cargo check -p loom-web
cargo test -p loom-web

# Build
cargo leptos build --release

# Deploy
docker build -f docker/Dockerfile.web -t loom-web .
docker push ghuntley/loom-web

# Fix Leptos errors
cargo check -p loom-web 2>&1 | grep "error\["
# Then follow LEPTOS_0_7_MIGRATION_GUIDE.md
```
