PATTERNS IMPLEMENTED
====================

ReadFile Pattern:
  Triggers: "I need to read", "let me read", "show me", "read", "get file"
  Pattern: r"(?i)(?:i need to read|let me read|show me|read|get file)\s+(?:the\s+)?(?:file\s+)?([^\s,;?!]*[/\.][^\s,;?!]*)"
  Extraction: Path with normalization (quote removal, prefix addition)
  Timeout: 10 seconds

ExecuteCommand Pattern:
  Triggers: "run", "execute", "run command"
  Pattern: r"(?i)(?:run|execute|run command)\s+(.+?)(?:\s+or\s+|\s+and\s+|$)"
  Extraction: Command + arguments via whitespace splitting
  Timeout: 30 seconds

GetEnvironment Pattern:
  Triggers: "get environment", "what's in", "show me env", "check env"
  Pattern: r"(?i)(?:get environment|what's in|show me env|check env)\b(?:\s+(.+))?$"
  Extraction: Variable names with uppercasing
  Default: [PATH, HOME, USER, SHELL, LANG]
  Timeout: 10 seconds

RequestUserInput Pattern:
  Triggers: "ask user", "request user", "prompt user"
  Pattern: r"(?i)(?:ask|request|prompt)\s+(?:the\s+)?user(?:\s+(.*))?$"
  Extraction: Prompt text from remaining input
  Default: "Please provide input"
  Timeout: 60 seconds

LOGGING INSTRUMENTATION
=======================

handle_llm_output():
  Fields:
    - session_id: String (correlation)
    - output_len: usize (input size)
  Debug Logs:
    - Query detection results
    - Processing first query
  Info Logs:
    - Query processed successfully
  Warn Logs:
    - Query processing failed
    - Timeout occurred

handle_llm_output_batch():
  Fields:
    - session_id: String
    - output_len: usize
  Debug Logs:
    - Batch processing start
    - Each query processing
  Info Logs:
    - Batch completion
  Warn Logs:
    - Individual query failures

QUERY OBJECT STRUCTURE
======================

All queries include:
  - id: "Q-{uuid}" (String)
  - kind: ServerQueryKind (enum)
    - ReadFile { path: String }
    - ExecuteCommand { command: String, args: Vec<String>, timeout_secs: u32 }
    - GetEnvironment { keys: Vec<String> }
    - RequestUserInput { prompt: String, input_type: String, options: Option<Vec<String>> }
  - sent_at: RFC3339 timestamp (String)
  - timeout_secs: u32 (per-type)
  - metadata: serde_json::Value { "detector": "simple_regex" }
