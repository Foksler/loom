DEPLOYMENT INSTRUCTIONS
================================================================================

Quick Start (Docker Compose):
  1. cp docker/.env.example .env.production
  2. nano .env.production (edit database URL, etc.)
  3. docker-compose up -d
  4. curl http://localhost:3000 (verify UI)
  5. curl http://localhost:8000/metrics (verify API)

Kubernetes Deployment:
  1. docker build -t registry/loom:latest .
  2. docker push registry/loom:latest
  3. kubectl apply -f deployment/k8s/
  4. kubectl port-forward svc/loom-web 3000:3000

Binary Installation:
  1. cargo build --release
  2. cp target/release/loom-* /opt/loom/bin/
  3. Set up systemd service
  4. systemctl start loom-server loom-web
  5. systemctl enable loom-server loom-web

See DEPLOYMENT_READY.md for detailed instructions.
